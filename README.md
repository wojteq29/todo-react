# 📝 Todo List App

Prosta aplikacja typu **To-Do List** stworzona w oparciu o **React + Vite**.  
Projekt powstał jako ćwiczenie podstaw programowania w React i pokazuje pracę ze stanem, komponentami oraz obsługą zdarzeń.

---

## ✨ Funkcjonalności
- ➕ Dodawanie nowych zadań  
- ✅ Oznaczanie zadań jako ukończone  
- 🗑️ Usuwanie zadań z listy
- 📱 Responsywność aplikacji
  
---

## 🛠️ Technologie
- [React](https://react.dev/)  
- [Vite](https://vitejs.dev/)  
- [JavaScript](https://developer.mozilla.org/pl/docs/Web/JavaScript)  
- [SCSS](https://sass-lang.com/)  

---

## 🚀 Uruchamianie projektu lokalnie

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/wojteq29/todo-react.git
   cd todo-react
   ```

2. Zainstaluj zależności:
   ```bash
   npm install
   ```
   
3. Uruchom serwer deweloperski:
   ```bash
   npm run dev
   ```
   
4. Aplikacja powinna być dostępna pod adresem:
   http://localhost:5173
